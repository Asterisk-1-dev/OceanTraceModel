* **Role**: Lead Software & ML Implementation Engineer

* Implement the multi-factor probabilistic vessel responsibility scoring algorithm.
* Develop FastAPI backend services serving incidents, GeoJSON layers, live simulation playback, and reporting.
* Integrate backend data pipelines into the approved React 19 frontend UX baseline (`App.jsx`, `Report.jsx`).
